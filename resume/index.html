Found 4 holes in gradecore's own graders and 8 in ports of a widely-used framework's assertions; fixed three fail-open graders in gradecore 0.10.3. 325 tests.
• deadgate: a linter for CI checks that cannot fail in GitHub Actions workflows (PyPI). Across 275 repositories I hand-labelled all 653 of its findings and deleted two of its four detectors that the labels showed had never once been right: 36.1% false, measured rather than estimated. Found an unguarded required status check in heygen-com/hyperframes, fixed by my merged PR #5182. 228 tests.
• deadcheck: does an eval rubric catch what it claims? Run on three rubrics I did not write: OpenAI evals' Match accepts "10" for ideal "1"; a promptfoo example passes refusal-then-compliance. Seven probe rounds found 23 defects in deadcheck itself under a passing suite. 185 tests.
• rag-eval-lab: deterministic RAG eval harness that catches a planted hallucination in CI; from-scratch BM25 matching the published SciFact baseline (0.664 vs 0.665). 60 tests.
• agent-graph: a LangGraph ReAct agent with unit-testable multi-step tool use: a swappable mock/LLM policy runs it deterministically without a key; a safe AST calculator (no eval); a max-step guard. 67 tests.
• harness-builder: More scaffolding scored worse, for 22x the cost. Three harness shapes on one 20-task suite, zero errors in 60 runs: one drafter 95%, planner plus drafter 90%, four-call panel with judge 80%. The panel won 0 of 20 tasks, and the tool reported “this suite cannot decide” rather than ranking.
• tapdodge-engine: One rulebook, two runtimes, and a check that fails when they stop agreeing: a JVM-versus-browser (TeaVM) differential in CI. In a committed fault injection it was the only check that caught a runtime-supplied-RNG fault; the same-runtime determinism test and the golden file both passed it.
